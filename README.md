# Rahab Mwanza | Portfolio

React + Vite personal portfolio (mint green theme).

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

## Add your photo
Put your picture in `public/profile.jpg` (square, at least 400x400). It appears inside the hero ring.

## Deploy on Netlify
1. Push this folder to a GitHub repo.
2. On netlify.com: Add new site > Import an existing project > GitHub > pick the repo.
3. Build command `npm run build`, publish directory `dist` (already set in `netlify.toml`). Deploy.

Edit your content at the top of `src/App.jsx`.
